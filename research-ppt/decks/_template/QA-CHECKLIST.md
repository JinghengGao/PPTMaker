# PPT 逐页 QA

- [ ] 所有页面均实际检查，临时截图验收后清理
- [ ] 标题、正文、图注不存在裁切、重叠或异常换行
- [ ] 中英文字体可用且与所选主题一致
- [ ] 图片与 SVG 清晰、比例正确，图片路径构建后正常
- [ ] 技术流程图中的节点、数据流和反馈箭头经内容审查
- [ ] 实验结果、论文图片和引用有可靠来源
- [ ] 各页面沿用目标模板的网格、颜色与信息层级
- [ ] 与参考 PPT 的代表性页面并排对照，说明差异
- [ ] PDF 导出实际打开并检查
- [ ] 可编辑 PPTX 单独实际打开检查：原生文字、表格、图像、公式与换行
- [ ] exports/v<版本>/ 中只有 PDF、可编辑 PPTX 两份成品
- [ ] 同版本重导失败时保留原成品；成功后替换；其他版本和 deck 未受影响
