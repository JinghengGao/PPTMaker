# 科研演示流程

## 新演示

用 New 创建 deck，填写任务书，选择主题、受众、资料来源和目标页数。编辑该 deck 的 slides.md，素材放入同 ID 的 public/decks 目录，QA.md 记录当前检查结论。

每页一个主要观点，事实、用户贡献、论文图片与示例数据清楚区分。不编造论文或实验结果；内容多时重排或拆页，不持续缩小字号。

## 从参考创建主题

1. 在 references/inbox 发现真实参考文件，原件只读，复制到唯一归档并记录来源。
2. 渲染观察所有页面，记录字体、配色、布局、标题与页脚的页码依据；未知值写待确认。
3. 遵循 [主题规范](../research-ppt/templates/_template/README.md) 建立独立本地主题；区别原稿布局与延伸设计，不沿用作者身份或论文图片作为默认内容。
4. 用代表性样例逐页比对和检查。参考预览是设计依据；日常导出截图仅作临时验收，不持续积累。

参考分析和对照工具见 [脚本索引](../research-ppt/scripts/README.md)。字体只记录名称，不打包受版权保护的文件。

## 验证与交付

Preview 直接预览当前 deck。Export 按版本生成 PDF 和可编辑 PPTX，Check 实际打开渲染，结束后删除临时检查文件。可添加 PreviewUrl 检查浏览器，已知工具链问题需显式接受。

人工查看最终 PDF/PPTX，核对所有页面的字体、换行、图像比例、公式、箭头和内容；QA.md 只保留当前结论。每一版的两份成品均保留，同版本重导成功后替换，不保存旧截图、日志、备份或源稿快照。
