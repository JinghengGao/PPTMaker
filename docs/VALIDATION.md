- 当前锁定的 Slidev 53 工具链存在 FloatingVue / Twoslash 的 Popper 控制台兼容报错。浏览器 QA 默认严格失败，显式接受已知条目后会标记带已知问题通过；不会接受任意页面错误。
- npm 安装曾报告现有锁定依赖的 21 项审计问题，本次不进行破坏性升级。
- SVG、公式与复杂效果可能在可编辑 PPTX 中保留为图片；字体不打包。
- 优先支持 Windows，未验证 macOS/Linux。缺少 PowerPoint 时的原生渲染会跳过。
