# 常用 AI 提示词

替换方括号中的信息，让代理先阅读根 AGENTS 与 README。AI 工具自行安装和登录；工程不提供模型密钥或 API。

## 从参考建立主题

```text
请分析 references/inbox 中的 [真实文件名]，创建本地主题 [新ID]。
原件只读并复制归档。完整渲染，逐页记录设计证据；未知属性写待确认。
按 templates/_template 建立独立主题与 5–8 页样例，区分原稿布局与延伸设计。
逐页截图比对，验证浏览器、PDF、两种 PPTX 与既有作品回归，记录限制。
参考和主题先保持本地，不上传或强制加入 Git。
```

## 制作新演示

```text
请使用 [default 或本地主题ID及版本]，基于 [本地资料] 制作 [主题] 演示。
Deck ID：[ID]；受众：[受众]；时长：[时长]；页数：[页数]。
作者与单位：[自己提供或留空]；输出版本：[X.Y.Z]。
先填写 brief；不编造论文、数据或结果，缺失资料明确占位。
源稿、资源、QA 按 deck 隔离；逐页预览检查，导出三种格式。
不得修改其他作品或更换指定主题。
```

## 修改或核查

```text
请修改 deck [ID] 的第 [页码] 页，目标：[具体要求]。
改前备份，保留其他页面与主题；核查论文、数字和引用，区分事实与假设。
不要靠缩小字号解决溢出，检查图片路径、公式、箭头和文字换行。
使用版本 [X.Y.Z] 导出，重导需归档旧版；记录修复与未验证项。
```

## 更新模板

```text
请更新主题 [ID@版本] 的 [规则]，先备份并建立新版本。
以 STYLE-GUIDE 和参考证据为依据，专属逻辑不进入全局。
逐页比较典型样例和受影响 deck，不覆盖旧交付物。
```
