# 数据与比较的表达

本指南由 PPTMaker 围绕科研汇报独立编写。设计研究背景见 [项目 Skills 说明](../../../../docs/SKILLS.md#设计研究参考)；图表来源与数值以实际材料为准。

用于数据图表和比较表。数字仅作为步骤编号时，仍按普通关系图处理，不因出现数字而强制绘制统计图。

## 先确认比较是否成立

明确本页要比较什么，核对指标定义、单位、方向、样本或数据集、评估方式和模型条件。不同测试集、输入设置、采样策略、统计口径或单模型/集成结果，不能不加说明地放在同一排名中。

在 brief.md 中记录必要条件和数据出处，页面上保留影响理解的条件。资料缺少数值、类别或定义时先指出缺口；不沿用示例中的数字，不凭曲线外观估读精确结果，也不生成貌似真实的实验数据。

## 按读者的问题选择表达

| 读者需要做什么 | 可考虑的表达 |
| --- | --- |
| 查找精确值、参数或多项条件 | 简洁表格，清楚区分表头、单位和缺失值 |
| 比较几个类别的大小或差异 | 条形、点图或并列表；重点直接对应待比较对象 |
| 查看连续变化 | 折线及合适的连续轴；保留真实间隔和缺失段 |
| 查看两项数值之间的联系 | 散点等按数值定位的表达；不据此自动下因果结论 |
| 查看分布或不确定性 | 使用资料实际提供的分布、区间或原始图；没有时不补造 |
| 理解组成 | 在分母、分类和总量明确时展示组成，并保留可核对的数值 |

这些是选择依据，不是固定目录。原有科学图像或出版图能清楚支撑观点时可直接引用；不为满足某种图形偏好而重绘证据。

## 保证视觉编码和数值一致

柱长、点位、面积等用于表达数量时，应由真实值和明确尺度计算。相同比较任务使用可比尺度；以柱长表达大小通常从零开始，非零范围或断轴必须显式标明，避免夸大差异。需要看局部变化时可换成更适合的表达，并注明范围。

横轴有真实时间或顺序时保留它。类别排序服务于比较问题，不随意改变有语义的顺序。同一对象跨页保持可识别的颜色或标记；强调色只帮助定位重点，不擅自表示统计显著、因果或优劣判定。

数值、单位、轴、图例、表头和注释应互相对应。Top-1 与 Top-5、准确率与错误率等不同指标分清，并说明高低方向。缺失值用可解释的标记，不填零；有效小数位与来源一致，不能制造额外精度。

百分比的直接相减是百分点差；相对变化需明确分母。例如从一个比例变到另一个比例时，说明使用的是差额还是相对变化，不混用两种措辞。派生值保留计算依据，不能把演示中的计算冒充原文直接报告。同页涉及多种比较时，让每个差值紧邻其比较对象；总结也要区分不同条件变化的收益，避免把一个差值接到另一个比较的结论上。

## 表格、标注与结论

表格每一行保持比较条件可理解；不同来源或条件用列、分组或注释区分。内容过多时围绕当前问题选择必要列，并保留完整依据可供追溯；不能删掉改变排名或解释的条件。

标签放在读者容易对应的位置。结论指出具体比较及支持它的证据，不能只写“效果显著”。只有来源或相应统计分析支持时才使用统计显著性表述。原文没有区间或重复实验信息时如实保留这一范围，不自行添加误差线。

在页面标注可解析的出处和必要条件，至少能追溯到原表、图或数据位置。发布前逐项核对数值、图形编码、比较条件及结论；现有导出中的形状、图片与原生图表是不同对象，不因图表内容可改就宣称有原生“编辑数据”能力。
