# 把内容安排成可读页面

本指南由 PPTMaker 围绕 Markdown/Vue 与现有主题独立编写。设计研究背景见 [项目 Skills 说明](../../../../docs/SKILLS.md#设计研究参考)。

用于制作页面或调整视觉表达。先读所选主题的 STYLE-GUIDE.md 和实际布局；局部设计在现有正文区内实现，必要样式留在目标 deck，不改公共主题来迁就单页。

## 先核对关系，再安排图形

方法图开始前，明确输入、处理单元、连接、分支、汇合与输出。图上的每根有方向的线都应能说明传递或依赖什么；先后顺序、因果关系和并行处理不能互相替代。

根据资料安排空间：共同起点的分支可共享起点；需要汇合的路径交代汇合操作；父子关系与同级比较使用可区分的层级。相加、拼接、选择和重复执行应标清含义。没有依据时不补反馈环、不补对称结构，也不把两个不同角色画成相同权重只为整齐。

比较页面先找可对齐的项目，例如输入、步骤、条件、指标或输出，再决定并列还是分行。结构确实相同时可以重复构图，差异放在对应位置；不能通过删掉一方的必要内容形成表面上的平衡。

**示例**：若来源明确为“两路分别处理后汇合”，应表达两个分支及汇合点；不要把两个处理画成前后串行。图形外观由主题和可用空间决定，不预设圆形、卡片或箭头数量。

## 确定阅读重点和空间

先安排承载核心信息的图、表或文字，再放解释和来源。标题、核心信息、解释、注释应能区分；重点可通过位置、字号、留白或少量强调体现，避免所有内容同时加粗着色。

以正文区的实际边界安排布局，给图内标签、公式上下标和长中文留出空间。整体拥挤时先消除重复、改变排列或拆页；局部拥挤时调整相应区域，不机械地缩小整页。主题已有的标题、页脚和品牌元素不因通用设计偏好而移除。

图内标签应靠近所解释的对象，连线尽量避免穿过文字。安排紧凑结构时，标签本身也要占据空间；框与框之间有间距，不代表放入标签和箭头后仍然可读。交叉确有意义时，应能看清交叉处是否连接。装饰可以删去而不损失信息；不能让装饰暗示不存在的分类、数值或关系。

## 图文与图片

先判断图片在本页承担证据、解释对象、细节展示还是氛围作用。证据图和需要完整阅读的图表保留有效范围、坐标、图例和比例尺；局部放大时保留原图定位或说明裁切位置。不得拉伸图片，也不为构图美观遮住决定解释的部分。

文字用于指出读图位置和解释，与图保持清楚的对应关系。多图比较统一可比的尺寸、标记与顺序；确有不同尺度时明确说明。无信息作用的图标或配图无需加入；生成图片不能冒充观测或实验结果。

## 在 Slidev 中实现并检查

正文、数值与说明优先保留为真实文字；图形可用本地 HTML/CSS、Vue 或必要的 SVG。避免把整页烘焙为图片。复杂 SVG 或公式的 PPTX 可编辑范围仍由现有导出能力决定。

SVG 的坐标、字号与页面缩放需要一起考虑；样式系统也可能覆盖展示属性。明确文字单位，实际检查图内标签的最终大小，不仅检查外围容器是否越界。公式检查基线、上下标与相邻内容的间隔。

预览后逐页查看重点、关系、标签、图注和边界；导出后再核查实际成品。若只在某个对象或某个格式中异常，先修正目标 deck 的局部实现，不扩大到全局重设计。
