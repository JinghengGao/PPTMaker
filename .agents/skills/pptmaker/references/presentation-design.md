# 从资料组织演示

本指南由 PPTMaker 围绕现有工作区独立编写。设计研究背景见 [项目 Skills 说明](../../../../docs/SKILLS.md#设计研究参考)，执行命令仍按主 Skill。

用于新建、组织提纲或重构主线。局部文字修改、仅写讲稿或仅导出时，不要求重新规划整套演示。

## 先确定听众需要理解什么

从已有任务中提取受众基础、用途、时间和必须保留的材料。用一句话说明听众听完后应能解释、判断或决定什么；这些信息已明确时直接使用，不重复询问。

研究汇报围绕可核实的工作组织：问题为何值得讨论、方法解决哪一部分、什么证据支持结论、哪些条件限制解释。根据实际工作取舍顺序和篇幅，不把论文目录逐节压缩成幻灯片，也不强制每套都有相同章节。

## 在现有 brief.md 中写清页面任务

逐页提纲保持原有简洁格式，说明：

- **页面任务**：这一页解决听众的哪个疑问。
- **核心观点**：本页要讲清的一项信息；尚不能下结论时明确写成问题或待确认项。
- **依据**：对应资料、页码、图表号或已核实网址，以及必须保留的条件。
- **信息关系**：确实存在的先后、分支、包含、对比等关系；没有关系时不用硬补。
- **表达安排**：用文字、原图、表格、图表或示意图的理由，以及哪一块是阅读重点。

数据页按需附指标定义、单位和实验条件。这里只记录制作所需判断，不再创建第二份大纲、设计锁或固定字段的机器文件。

标题尽量让读者知道本页在说明什么。诸如“实验结果”的章节标签可以保留，但应由可见的观点或问题帮助读者理解图表。图中仅有现象时，不把解释性假设写成已证明的结论。

## 分配篇幅与细节

先保留支持核心观点的材料。定义、符号、比较条件和改变结论的限制不能为留白而删掉；重复背景和与主线无关的细节可以压缩或移到补充页。无法在指定页数内保持可读时，说明冲突并按授权调整，不能靠极小字体解决。

图表页通常围绕读图任务组织；方法页围绕机制或步骤组织；总结页回答开头提出的问题。页面形式可以变化，不以“每页必须一张图”或“每页必须三点”作为目标。

同一项研究对象在全套中使用一致名称与符号。区分文献结果、用户自己的结果、作者解释和本次汇报的归纳；研究来源不因被重新排版而变成演示者的成果。

## 示例：把话题改成可执行的页面任务

若资料讨论“两种处理方式在同一任务上的差别”，提纲可写成“让读者看清两种方式在哪一步不同，证据来自原文图示，采用并列结构并对齐相同阶段”。这只确定信息任务；实际分栏、字号和留白仍结合主题与内容决定。
